# Project Source — Architecture & Requirements

> **📋 TEMPLATE DIRECTORY — Populate during `/setup`**

This folder stores your project's architecture documents, requirements specifications, and project planning files.

## What Goes Here

- `Requirement.md` — Functional and non-functional requirements
- `ARCHITECTURE_GUIDELINES.md` — Technical architecture decisions
- `Project Plan.md` — Project timeline and milestones
- Any PRD (Product Requirements Document) files

## AI Agent Instructions

When this directory is empty or contains only this README:
1. **DO NOT assume any project requirements exist.**
2. During the `/setup` workflow, guide the user through defining their project scope.
3. Generate the requirement and architecture files based on user input and save them here.
4. After populating, CORE-01 Bootloader and CORE-03 Discovery will reference these files for context.
