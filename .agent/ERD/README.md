# ERD — Entity Relationship Diagrams

> **📋 TEMPLATE DIRECTORY — Populate during `/setup`**

This folder stores your project's database schema definitions. Place your ERD diagrams, Prisma schema files, or any database modeling documents here.

## What Goes Here

- `schema.prisma` — Your Prisma ORM schema definition
- `erd.md` — A markdown-based ERD diagram
- Any SQL migration files or database planning documents

1. **DO NOT assume any database schema exists.**
2. During the `/setup` workflow, guide the user through defining their data models.
3. Generate the ERD/schema files based on user input and save them here.
